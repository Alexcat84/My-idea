# Organizador de tu idea

**En una frase:** Aplicación con tecnología sonar para que personas ciegas se orienten mediante alertas sonoras en tiempo real

**Etapa detectada:** ideacion

## Lo que ya tienes claro
- Existe un problema de movilidad y orientación para personas ciegas
- La tecnología sonar y las alertas sonoras son un medio viable para solucionarlo
- El formato es una aplicación digital

## Lo que estás asumiendo sin saberlo
- Que las personas ciegas quieren recibir información principalmente por sonido
- Que el sonar es más preciso o útil que otras tecnologías de sensado existentes para este contexto
- Que la precisión en tiempo real es lo que más impide que se orienten hoy
- Que una app es el medio más accesible para llegar a este público
- Que los costos del hardware sonar son asequibles para el usuario final

## Áreas que cubriría tu plan completo
- Necesidades reales no articuladas de tu usuario (cómo se orienta hoy, qué le frustra)
- Supuestos críticos de valor y viabilidad técnica
- Primeras pruebas con prototipos básicos o conversaciones con usuarios
- Modelo económico y acceso a tecnología
