  NODO decision_pivotar_o_proceder
    titulo: Decisión: Pivotar o Proceder
    fuente: The Startup Owner's Manual - Blank, Steve
    entregable: Documento de decisión de pivotar o proceder, con checklist completado, Business Model Canvas actualizado y evidencia de las pruebas de éxito y fracaso realizadas
       1. Revisa honestamente si la validación convirtió opiniones en hechos, y no que moviste las metas para que coincidieran con el resultado
       2. Confirma que el producto se vendió bien y fácilmente, que la llegada de clientes es predecible, escalable y rentable, y que existe un proceso de ventas repetible
       3. Verifica que los tiempos de entrega del producto sean realistas con tu equipo de desarrollo
       4. Toma un Business Model Canvas nuevo y busca game changers revisando propuesta de valor, precios, canales y relaciones con clientes, no solo mejoras incrementales
       5. Presenta tu canvas a tu consejo asesor para que lo cuestione activamente
       6. Actualiza el canvas con lo aprendido y decide formalmente si pivotar volviendo a descubrimiento o proceder avanzando a creación de clientes
  ---
  NODO lienzo_modelo_negocio
    titulo: El Lienzo de Modelo de Negocio (Business Model Canvas)
    fuente: Business Model Generation - Osterwalder, Alexander
    entregable: Lienzo de Modelo de Negocio completo con los 9 bloques definidos y coherentes entre sí
       1. Imprimir el lienzo en tamaño grande para trabajo colaborativo y un Business Model Canvas para cada miembro del equipo
       2. Reunirse con el equipo aceptando que habrá vacíos en la primera versión
       3. Escribir cada bloque en notas post-it sobre el lienzo
       4. Identificar los segmentos de clientes a los que se dirige la organización
       5. Definir la propuesta de valor para cada segmento
       6. Mapear canales, relaciones y fuentes de ingresos
       7. Mapear recursos, actividades y asociaciones clave
       8. Calcular la estructura de costos y el profit resultante
       9. Pausar para investigar más información donde haya vacíos importantes
      10. Iterar y discutir en grupo hasta lograr coherencia entre los bloques
      11. Publicar el canvas en el espacio de trabajo y actualizarlo conforme avanza el proyecto
      12. Usar el lienzo como base para pivotar o validar hipótesis del negocio, y también para llevar una solución ya diseñada a un modelo de negocio viable

  NODO lean_launchpad_web_startup_process
    titulo: Proceso Lean LaunchPad para Construir un Startup Web
    fuente: The Startup Owner's Manual - Blank, Steve
    entregable: Sitio web funcional de alta fidelidad con métricas de tráfico, feedback de usuarios y sistema de cobro implementado
       1. Configurar la logística del equipo (blog, comunicación)
       2. Redactar las hipótesis del modelo de negocio de 9 bloques
       3. Escribir una propuesta de venta única (Unique Selling Proposition) en formato 'Ayudamos a X a hacer Y haciendo Z'
       4. Configurar dominio y hosting del sitio web
       5. Construir un sitio web de baja fidelidad (splash page, formularios de pre-orden)
       6. Dirigir tráfico de clientes potenciales al sitio para probar segmento y propuesta de valor
       7. Conectar la interfaz de usuario con el código backend
       8. Probar el 'problema del cliente' recopilando datos mediante analytics y encuestas
       9. Construir una versión de alta fidelidad para probar la 'solución'
      10. Pedir dinero mediante formularios de pre-orden o cobro real
