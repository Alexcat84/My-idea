MADRE : waterfall_vs_agile_development | Waterfall Development vs Agile Development
   1. Evaluar si el contexto del proyecto requiere certeza total de requisitos (waterfall) o iteración (agile).
   2. Para startups en fase de búsqueda, preferir metodologías ágiles que permitan pivotar.
   3. Alinear el proceso de desarrollo de producto con el proceso de Customer Development. <<< PASO CASADO
   ENTREGABLE: Una decisión documentada sobre la metodología de desarrollo de producto a utilizar.
------------------------------------------------------------------------------------------
HIJO : modelo_customer_development | Modelo de Customer Development (4 Pasos)
   1. Identificar en qué paso del proceso se encuentra la startup actualmente
   2. Formular hipótesis de negocio antes de iniciar cualquier paso
   3. Diseñar experimentos para testear cada hipótesis fuera del edificio
   4. Evaluar en cada 'stop sign' si se alcanzó 'velocidad de escape' antes de avanzar
   5. Estar dispuesto a retroceder a pasos anteriores si el aprendizaje lo indica
   ENTREGABLE: Diagrama de flujo del proceso de Customer Development con indicación clara del paso actual y evidencia de aprendizaje acumulado

MADRE : build_measure_learn | Ciclo Build-Measure-Learn (Lean Startup)
   1. Paso 0: Generar una hipótesis clara a partir de los Canvas de Value Proposition y Business Model <<< PASO CASADO
   2. Paso 1: Diseñar/construir un artefacto (prototipo conceptual, experimento o MVP) para testear la hipótesis
   3. Paso 2: Medir el desempeño del artefacto
   4. Paso 3: Aprender comparando lo esperado vs lo ocurrido y definir qué cambiar
   ENTREGABLE: Un ciclo completo documentado de Build-Measure-Learn con hipótesis, artefacto de prueba, métricas y aprendizajes registrados
------------------------------------------------------------------------------------------
HIJO : value_proposition_canvas | Value Proposition Canvas
   1. Descargar el template del Value Proposition Canvas
   2. Dibujar el círculo del Customer Profile a la derecha, especificando en él los jobs, pains y gains del cliente
   3. Dibujar el cuadrado del Value Map a la izquierda, documentando en él cómo tu producto/servicio alivia pains y crea gains
   4. Trabajar ambos lados iterativamente hasta encontrar Fit
   5. Comunicar ambos documentos a toda la organización para crear entendimiento compartido.
   6. Usar los documentos como scoreboard durante conversaciones reales con clientes.
   ENTREGABLE: Canvas completo con Customer Profile y Value Map mapeados para un segmento específico

MADRE : obtencion_compromiso | Cómo lograr un compromiso (más allá del cierre de venta tradicional)
   1. Define para cada llamada un objetivo de avance realista en vez de buscar el cierre inmediato
   2. Evita las técnicas de cierre de presión (cierre asumido, alternativo, última oportunidad) cuando la venta es compleja
   3. Mide el éxito de tus llamadas por los avances que logras, no solo por los pedidos que cierras
   4. Pon tu esfuerzo de mejora en las etapas de investigación y demostración de capacidad, no en el cierre <<< PASO CASADO
   ENTREGABLE: Una lista clara de qué cuenta como avance válido en cada etapa de tu proceso de venta
------------------------------------------------------------------------------------------
HIJO : enfoque_etapa_investigacion | Priorizar la Etapa de Investigación sobre Demostración de Capacidad
   1. Al planificar una llamada, dedica más tiempo a diseñar preguntas que a preparar el discurso de producto.
   2. Evita mostrar beneficios o capacidades hasta haber desarrollado suficientemente el problema y su implicación.
   3. Evalúa tus llamadas pasadas: ¿cuánto tiempo hablaste de tu producto en la primera mitad? Si es mucho, ajusta tu enfoque.
   4. Entrena primero en preguntas de Situación y Problema antes de avanzar a Implicación y Necesidad-beneficio.
   5. Usa las respuestas del cliente para desarrollar y ampliar la percepción de sus propias necesidades
   6. Practica escuchar de verdad para detectar problemas que el cliente no dice de manera directa
   ENTREGABLE: Una checklist de planificación de llamada de ventas centrada en preguntas de investigación, con métricas de tiempo dedicado a cada etapa del call.
