NODO: brainstorming
------------------------------------------------------------------------------
  dominio           : quality
  fase_proyecto     : ideacion
  titulo_concepto   : Brainstorming (Tormenta de Ideas)
  fuente            : Juran's Quality Handbook_ The C - Joseph A. Defeo
  etiqueta_arbol    : Lanza tu Lluvia de Ideas
  deprecado         : None
  resumen_teorico   :
      Técnica grupal para generar ideas creativas y constructivas de todos los participantes, sin juicio ni evaluación durante la generación. Es efectiva para desarrollar listas de teorías, ideas u opiniones, pero no debe usarse para probar teorías, que requieren datos.
  pasos_accionables : 7
      1. Formular claramente la pregunta o tema a discutir
      2. Comunicar el tema con anticipación y preparar espacio para contribuciones
      3. Revisar reglas conceptuales: sin críticas, ser poco convencional, buscar cantidad, aprovechar ideas de otros
      4. Revisar reglas prácticas: contribuir por turnos, una idea por turno, se puede pasar
      5. Realizar una sesión de calentamiento antes de iniciar
      6. Registrar todas las ideas visibles para todos y detener antes de la fatiga del grupo
      7. Procesar las ideas generadas (clarificar y eliminar duplicados)
  entregable_esperado:
      Lista de ideas generadas por el grupo, procesada y lista para su categorización
  condiciones_activacion: ["Cuando se necesita generar múltiples ideas o teorías sobre un problema o necesidad de mejora"]
  nodos_previos     : ["fijacion_de_metas", "brainstorming_efectivo"]
  nodos_siguientes  : ["diagrama_afinidad", "diagrama_causa_efecto"]

  dominio           : core
  fase_proyecto     : ideacion
  titulo_concepto   : Brainstorming como Generador de Divergencia
  fuente            : Change by Design, Revised and U - Tim Brown
  etiqueta_arbol    : Abre Posibilidades sin Filtro
  deprecado         : None
  resumen_teorico   :
      El brainstorming es una técnica clave para abrir un amplio espectro de ideas durante la fase divergente del design thinking. No es la única técnica de generación de ideas, pero es insuperable para crear opciones antes de pasar a la fase de convergencia donde se toman decisiones.
  pasos_accionables : 4
      1. Reunir al equipo en un espacio dedicado sin distracciones
      2. Establecer reglas claras: cantidad sobre calidad, diferir el juicio, construir sobre ideas de otros
      3. Generar el mayor número de ideas posible sin filtrar prematuramente
      4. Registrar todas las ideas visualmente (post-its, pizarra)
  entregable_esperado:
      Una colección amplia de ideas divergentes documentadas visualmente, lista para ser filtrada en fase de convergencia
  condiciones_activacion: ["Cuando el equipo necesita explorar múltiples soluciones posibles antes de comprometerse con una", "Cuando el problema aún no tiene una dirección clara de solución"]

NODO: brainstorming_efectivo
------------------------------------------------------------------------------
  dominio           : core
  fase_proyecto     : ideacion
  titulo_concepto   : Reglas para un Brainstorming Efectivo
  fuente            : Change by Design
  etiqueta_arbol    : Sigue Reglas para Idear Mejor
  deprecado         : None
  resumen_teorico   :
      El brainstorming es una forma estructurada de romper la estructura habitual del pensamiento; requiere reglas claras para funcionar bien, de lo contrario degenera en reunión ordenada o caos improductivo. La regla más importante es 'construir sobre las ideas de los demás', lo cual genera un efecto acumulativo de creatividad superior al trabajo individual.
  pasos_accionables : 4
      1. Establecer y visibilizar reglas claras: diferir el juicio, fomentar ideas descabelladas, mantenerse enfocado en el tema.
      2. Priorizar la regla de 'construir sobre las ideas de otros' por encima de generar ideas propias de forma aislada.
      3. Formar grupos donde los participantes se conozcan y tengan confianza mutua para evitar el escepticismo que reduce la generación de ideas.
      4. Dedicar sesiones específicas solo para generar opciones (divergencia), separadas de las sesiones de selección (convergencia).
  entregable_esperado:
      Una sesión de brainstorming documentada con un conjunto amplio de ideas generadas colaborativamente, listas para ser filtradas en fase convergente.
  condiciones_activacion: ["Cuando se necesita abrir un espectro amplio de ideas antes de tomar decisiones.", "Cuando el equipo no se conoce bien o carece de confianza para colaborar espontáneamente."]
  nodos_previos     : ["pensamiento_convergente_divergente", "cultura_de_optimismo", "esfuerzo_voluntario_vs_urge_espontaneo", "how_might_we_briefs", "intimation_illumination", "periodo_incubacion_mental", "sentido_del_humor_como_herramienta_de_pensamiento"]

NODO: reglas_brainstorming
------------------------------------------------------------------------------
  dominio           : core
  fase_proyecto     : ideacion
  titulo_concepto   : Reglas de Brainstorming Efectivo
  fuente            : Business Model Generation (Osterwalder)
  etiqueta_arbol    : Organiza tu Lluvia de Ideas
  deprecado         : None
  resumen_teorico   :
      Conjunto de reglas para maximizar la generación de ideas útiles en sesiones de lluvia de ideas: mantener el foco en un problema bien definido (idealmente centrado en la necesidad del cliente), diferir el juicio crítico, mantener una sola conversación a la vez, priorizar cantidad, pensar visualmente (Post-it) y fomentar ideas alocadas. Incluye un ejercicio de calentamiento ('Silly Cow') para desbloquear la creatividad.
  pasos_accionables : 5
      1. Definir un enunciado claro del problema centrado en necesidad del cliente
      2. Establecer y hacer cumplir reglas: diferir juicio, una conversación a la vez, ir por cantidad, ser visual, fomentar ideas locas
      3. Preparar al equipo con una experiencia de inmersión previa (visita de campo, entrevistas a clientes)
      4. Usar Post-it notes para capturar y mover ideas visualmente
      5. Opcional: realizar el ejercicio 'Silly Cow' como calentamiento creativo
  entregable_esperado:
      Sesión de brainstorming documentada con ideas capturadas en Post-its y agrupadas por tema
  condiciones_activacion: ["Cuando el equipo necesita generar gran volumen de ideas en poco tiempo", "Si las discusiones se estancan en crítica prematura de ideas"]
  nodos_previos     : ["equipo_diverso_ideacion", "cuatro_etapas_del_pensamiento_creativo", "equipos_visita_cliente", "etnografia_investigacion_usuario", "how_might_we_hmw"]
