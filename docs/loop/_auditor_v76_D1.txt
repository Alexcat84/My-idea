TITULO: Análisis de Capacidad de Proceso (Process Capability)
FUENTE: Juran's Quality Handbook_ The C - Joseph A. Defeo
RESUMEN: La capacidad de proceso mide si un proceso puede cumplir con las especificaciones del producto. Es fundamental distinguir entre un proceso bajo control estadístico (estable, sin causas asignables) y un proceso capaz (que cumple especificaciones). Ambos conceptos son independientes: un proceso puede estar fuera de control pero cumplir especificaciones, o estar en control pero no cumplirlas. El objetivo ideal es lograr procesos que sean tanto estables como capaces.
PASOS:
  1. Graficar mediciones individuales contra los límites de especificación
  2. Verificar si el proceso está en control estadístico mediante cartas de control
  3. Calcular la desviación estándar y los límites de capacidad del proceso
  4. Comparar los índices de capacidad (Cpk, Cpm) con las especificaciones usando un histograma
  5. Verificar los cinco supuestos clave: estabilidad, normalidad, datos suficientes, representatividad de muestras e independencia de mediciones

TITULO: Capacidad de Proceso mediante Monitoreo Estadístico
FUENTE: Out of the Crisis, Reissue - Deming, W. Edwards; Cahill, Kev
RESUMEN: Cada unidad estudiada (un operador humano, una máquina o un sistema) debe ser monitoreada durante un período de tiempo para determinar su capacidad de proceso: lo que puede hacer predeciblemente bajo las condiciones actuales. Esta capacidad usualmente puede determinarse en unos tres meses mediante cartas de control. Si la dirección determina que la capacidad del proceso no está dentro de límites aceptables, debe actuar sobre el proceso o sistema, ya que la calidad no puede exceder la capacidad del sistema y no puede ser inspeccionada dentro del producto, debe ser construida en él.
PASOS:
  1. Seleccionar la unidad a estudiar (persona, máquina, sistema)
  2. Recolectar datos de desempeño durante un período representativo (aprox. 3 meses)
  3. Construir cartas de control (run charts, control charts) para visualizar variación
  4. Determinar si el proceso está dentro de límites aceptables
  5. Si no lo está, intervenir sobre el sistema (no sobre el individuo)

TITULO: Capacidad del Proceso
FUENTE: Out of the Crisis, Reissue - Deming, W. Edwards; Cahill, Kev
RESUMEN: Una vez que un proceso está en control estadístico, tiene una capacidad definible y predecible: se puede calcular qué especificaciones puede cumplir de forma sostenida usando la media y el rango de los gráficos X-barra y R. Es un error común calcular capacidad tomando muestras arbitrarias sin antes verificar que el proceso esté en control.
PASOS:
  1. Verificar primero que el proceso esté en control estadístico (gráfico de corridas o X-barra/R)
  2. Calcular la media y el rango promedio del proceso estable
  3. Determinar la capacidad usando las fórmulas estándar (constantes d2, A2, etc.)
  4. Comunicar la capacidad real a diseño e ingeniería para ajustar especificaciones realistas

TITULO: Capacidad de Proceso
FUENTE: Juran's Quality Handbook_ The C - Joseph A. Defeo
RESUMEN: La capacidad de proceso mide la uniformidad inherente de un proceso para producir dentro de especificaciones. Se cuantifica desde la etapa de planificación y sirve para decidir sobre la adecuación de procesos, elección de alternativas, necesidad de rediseño y, en control, para definir la frecuencia de medición y mantenimiento: a mayor estabilidad, menor necesidad de medición frecuente.
PASOS:
  1. Recolectar datos históricos de desempeño del proceso
  2. Calcular índices de capacidad (uniformidad) del proceso frente a especificaciones
  3. Usar los resultados para decidir frecuencia de medición y mantenimiento
  4. Determinar si el proceso requiere rediseño o si es apto para producción
