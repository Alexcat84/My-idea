  FUENTE   : Quality is free _ the art of making quality certain -- Philip B_ Crosby
  DOMINIO  : quality

  DOMINIO  : core

  TITULO   : Bullseye Framework (Diana de Tracción)
  FUENTE   : Traction - Gabriel Weinberg
  DOMINIO  : core

  PASOS (12):
