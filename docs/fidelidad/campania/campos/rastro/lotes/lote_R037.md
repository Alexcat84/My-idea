- etiqueta: Limpia tus Datos Primero
- resumen: El cribado de datos consiste en detectar valores atípicos (outliers) o errores de transcripción antes del análisis. - titulo: Definición de Calidad como 'Fitness for Purpose'
- etiqueta: Ajusta tu Producto al Propósito
- resumen: Juran define la calidad como 'aptitud para el uso' (fitness for use), concepto que se amplía a 'fitness for purpose' para reflejar también la economía de servicios. Esta definición aplica tanto a bienes como a servicios y es la base conceptual para gestionar la calidad de forma consistente en tu negocio, sin importar su tamaño.
- entregable: Documento de definición de calidad que enumere las necesidades del cliente, las características requeridas del producto o servicio y los criterios de ausencia de fallas.
- condiciones:
  - condiciones[0]: Cuando existe confusión sobre qué significa calidad en tu negocio
  - condiciones[1]: Al iniciar cualquier iniciativa de gestión de calidad sin una definición previa
  - condiciones[2]: Cuando estás definiendo un proyecto o producto nuevo y necesitas establecer qué significa calidad para él

- entregable: Marco de medición de valor al cliente que incluya indicadores de desempeño e impacto extendido
- condiciones:
  - condiciones[0]: Cuando se requiere validar que las mejoras internas se traducen en valor real para el cliente
  - condiciones[1]: Cuando la organización busca evaluar impactos más allá del beneficiario directo
